AWS Event Announcement System

Built a serverless event announcement platform where users can subscribe to email notifications, view a list of events, and create new events through a web form.

Architecture: Static frontend (HTML/CSS) hosted on Amazon S3 with static website hosting. API Gateway exposes REST endpoints (/create-event and /subscribe) integrated with AWS Lambda. A Subscription Lambda adds new emails to an SNS topic, while an Event Registration Lambda updates events.json in S3 and broadcasts notifications via SNS. IAM roles and policies secure access to all AWS resources.

Challenges Overcome: Resolved Lambda syntax errors caused by code misalignment through careful indentation review. Fixed API Gateway deployment failures by correcting Lambda mappings, enabling CORS, and performing thorough API testing.
